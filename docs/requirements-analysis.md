## 2. 非功能需求

| 编号 | 指标 | 要求 |

| NFR-1 | 识别准确率 | > 90% |

| NFR-3 | 覆盖骗术类型 | ≥ 10 种 |
| NFR-4 | 文本 / 图片响应时延 | < 10 秒（交互预算 5 秒出结论） |
| NFR-5 | 通话流式首警时延 | ≤ 3 秒 |
| NFR-6 | 连续运行 | 无崩溃、无资源泄漏 |
| NFR-7 | 模态能力 | 文本 + 音频 + 视觉三者联合分析 |
| NFR-8 | 闭环 | 诱导－预警－监护人联动全链路 |
| NFR-9 | 知识库 | 自适应更新且不停机 |
| NFR-10 | 可解释性 | 禁止纯黑盒分数，须给证据链 |
| NFR-11 | 无障碍 | 字号 ≥24pt、高对比、语音播报、无术语 |

| NFR-14 | 可扩展 | 支持第三方数据源与新增模态 / 骗术 |
| NFR-15 | 并发 | 通过压力测试，有降级策略与并发 - 时延曲线 |
| NFR-16 | 可维护 | 依赖锁定、一键部署、配置外置 |
| NFR-17 | 可评估 | 分模态、分骗术报告，不只看总体均值 |

## 4. 验收标准

### 识别能力

- AC-01 跑自建测试集（≥20 案例，黑白 1:1，≥10 类骗术，含音频 / 视频）→ 准确率 >90% 且报告给出 F1（NFR-1）
- AC-02 跑灰样本（正常通话 / 工作群 / 营销短信 / 家庭转账）→ 误报率 <5%，误报可定位到触发规则（NFR-2）
- AC-03 逐类统计 10 种骗术 → 每类 ≥1 个样本判为高危，报告分类型给准确率（NFR-3 / 17）
- AC-04 提交未参与训练的合成语音 → 输出"疑似合成"或降级为"建议回拨核实"，不得输出"安全"（FR-2.7 / 2.8）
- AC-05 查看任一预警详情 → 有 ≥3 条判据 + ≥1 条相似案例（FR-2.4 / 2.10）

### 性能与稳定

- AC-06 文本或图片输入 → 平均响应 <10 秒，记录 P50 / P95（NFR-4）
- AC-07 通话流出现高危话术 → 3 秒内首警（NFR-5）
- AC-08 连续运行约定时长 / 请求量 → 无崩溃、无未处理异常，内存连接稳定（NFR-6）
- AC-09 逐步加压至并发上限 → 按策略降级不崩溃，输出并发 - 时延曲线（NFR-15）

### 多模态与闭环

- AC-10 同一事件的文本 / 语音 / 截图分别与联合提交 → 均可独立判别，联合结论置信度不低于单模态（NFR-7）
- AC-11 完整演示（诱导－识别－预警－监护人通知）→ 全链路可复现、无跳步（NFR-8）
- AC-12 导入一份新案例 → 向量库增量更新且不重启，检索可命中该案例（FR-4.1 / 4.2，NFR-9）
- AC-13 知识库 / 提示词变更后指标劣化 → 可一键回滚并复现原指标（FR-4.3）

### 角色化与体验

- AC-14 同一样本分别在老人与中青账户下运行 → 阈值与措辞不同（老人更敏感、结论式短句；中青更保守、低打扰）（FR-2.5 / 5.1，NFR-11）
- AC-15 判为高危 → 按分级执行干预，通报附动作卡（FR-3.1 / 3.2 / 3.3）
- AC-16 中青开启隐私模式后出现高风险 → 不向监护人推送，经用户确认才联动（FR-3.7）
- AC-17 点击"这不是诈骗" → 样本进入评测集并关联该用户阈值调优记录（FR-3.6）
- AC-18 查看老人端预警界面 → 字号 ≥24pt、无术语、结论可语音播报、主操作只有一个按钮（NFR-11）
- AC-19 核查任一次数据采集 → 有同意记录、可见范围说明与删除路径（NFR-12）

### 交付与复现

- AC-20 在干净环境按部署文档执行 → 无需口头指导即可跑通一次输入到预警（FR-6.5，NFR-16）
- AC-21 第三方重跑评测脚本 → 得到与评估报告一致的准确率与 F1（FR-6.3，NFR-17）
- AC-22 可运行程序、部署文档、使用指南、评估报告齐备（FR-6.5）

## 5. 待确认

1. 阈值是分角色独立配置，还是单阈值 + 角色偏移量
2. 隐私模式与"高风险自动联动监护人"的默认策略（建议：默认隐私模式，高危且预授权才联动）
3. 连续运行时长与并发上限需自定并写入评估报告
4. 青少年角色是否纳入本期实现（影响 FR-2.11 / 3.8 排期）
