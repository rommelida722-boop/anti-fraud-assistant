## 角色 A · 老人

### 用户画像

- 年龄：65–80 岁
- 职业：退休（工人 / 教师 / 个体 / 事业单位）
- 技能水平：只会微信语音视频、接打电话；不懂链接、验证码、权限
- 生活状态：独居或空巢，子女异地，管着家里的钱，关注养生

### 任务分析

- 核心任务：接到陌生来电 / 短信 /「子女出事」消息时，判断真假并安全处理
- 使用情境：通话中被要求"别挂、别告诉人"；收到带链接短信；被拉进投资养生群；银行 / ATM 转账前
- 现有方案：凭感觉判断；想问子女但怕挨骂；装了反诈 App 看不懂提示；等柜员拦住
- 方案痛点：没有判断标准；求助有心理成本；等子女回复来不及；弹窗术语看不懂；合成语音听不出假

### 三层次需求

- 功能需求：通话 / 短信 / 图片 / 链接实时分级，大字 + 语音 + 结论式短句；高危先劝阻再自动联动子女；拍照转发即查；给子女一份看得懂的报告
- 情感需求：被保护但不被当成傻子；在子女面前保住体面；慌乱时有"有人一直在"
- 社会需求：不因受骗失去家庭财政话语权；不被视为"落后"

### 验证计划

- 访谈对象：8–12 位 65+ 独居老人（含 2–3 位曾被劝阻）+ 5–8 位子女 + 2–3 位柜员 / 社区民警
- 观察方法：出声思维复述真实诈骗短信；社区现场试用 30 分钟看是否误触；演练"假扮子女借钱"电话
- 测试原型：字卡 + 录屏（大字预警页、语音播报、监护人弹窗），验证"看得懂 + 愿意被通知子女"

### JTBD 陈述

> 当独居老人接到冒充公检法 / 银行的来电、或微信上"子女"突然借钱时，
> 他们想要在不麻烦子女、不被说"老糊涂"的前提下判断真假并安全处理，
> 因为凭感觉判断、想问又怕挨骂、App 术语看不懂这几条替代方案存在"没有判断标准、求助有心理成本、等不起"的痛点。

### 解决方案

1. **核心功能**：通话实时判定 + 合成语音检测 + 分级干预（弹窗 / 语音阻断 / 自动拨监护人）+ 拍照转发即查 + 子女版报告
2. **体验重点**：一个入口一个按钮；不出现技术术语只给结论；提醒不公开不评判；正常来电绝不打扰
3. **技术约束**：方言 + 8kHz 电话信道 ASR；通话只有几秒阻断窗口需端侧流式；断网要离线兜底；通话录音需明示同意；监护人授权要防冒充

## 角色 B · 中青年

### 用户画像

- 年龄：22–40 岁
- 职业：公司职员、出纳 / 会计、自由职业、在校生
- 技能水平：数字化熟练、多账号多设备；高估自己抗骗能力
- 生活状态：节奏快、碎片化处理消息；有贷款 / 就业 / 育儿压力，对副业理财有真实需求

### 任务分析

- 核心任务：在多条并行消息里快速判断"这是不是骗局"，且不打断工作与社交
- 使用情境：工位上收到"领导 / HR"加好友转账；刷到刷单兼职；还贷前接到征信修复电话；会议中被"老板"要求付款
- 现有方案：自己复制话术去搜；问同事；银行风控短信；公司双人复核流程
- 方案痛点：判断疲劳；平台割裂无统一入口；AI 换脸 / 合成语音肉眼识不破；紧急催办会绕过制度；误报一次就关通知

### 三层次需求

- 功能需求：转发 / 截图秒级给"能信 / 不能信 / 再确认"+ 三句理由；覆盖刷单、贷款、理财、冒充熟人、换脸、游戏交易；轻量嵌入不打断；财会付款前校验 + 留痕
- 情感需求：自主感，不被当成需要看管的人；提醒给体面出口；"差点被骗"不被嘲讽
- 社会需求：在同事面前显得靠谱；财务岗能对职业责任有交代；能反过来保护父母

### 验证计划

- 访谈对象：10–15 位在职人员（含 2–3 名出纳）+ 5–8 名在校生 + 1–2 名财务负责人
- 观察方法：回放最近 30 天可疑消息记录决策路径；屏幕录制处理动作；测试集盲测记准确率与主观可信度
- 测试原型：可交互的"转发即查 / 截图即查"Demo + 理由卡片 + 报告样例，验证误报容忍度与留存意愿

### JTBD 陈述

> 当上班族收到"领导"转账指令、刷单兼职、征信修复电话或会议中被要求紧急付款时，
> 他们想要在最小打断下快速拿到"能不能信"的判断并留下证据，
> 因为自己搜、问同事、靠风控短信、走复核流程这几条替代方案存在"判断疲劳、平台割裂、换脸识不破、催办绕过制度"的痛点。

### 解决方案

1. **核心功能**：转发 / 截图即查 + 三档结论与理由 + 六类高发骗术覆盖 + 来电悬浮提示 + 财会对公校验留痕 + 相似案例检索
2. **体验重点**：只有高危才打扰；结论先行理由折叠；绝不在群里报警；提供"仅自己可见"隐私模式；5 秒内出结论
3. **技术约束**：微信 / QQ 无开放 API，只能走分享面板、剪贴板授权、OCR；换脸检测推理成本高需级联分流；合成样本泛化有限要允许降级为"建议核实"；聊天记录属敏感信息需最小化留存

## 角色 C · 青少年（扩展）

- **画像**：10–18 岁在校生；操作熟练但无金融常识；手机与账户由家长代管
- **场景**：游戏低价出皮肤、找代练、饭圈集资、学生日结兼职
- **痛点**：问家长会被没收手机；平台外转账后平台不受理；不懂"垫付""收款码"意味着什么
- **JTBD**：当学生想买皮肤 / 找代练时，他们想要买成又不被骗、还不被家长发现，因为问家长会被拒、投诉追不回、平台内交易常被诱导到私下转账。
- **方案**：游戏黑话识别（出金 / 包上分 / 低价代充）+ 收款码与垫付诱导拦截 + 支付前置家长确认 + 监护人联动为主路径，附止损指引
- **体验重点**：不羞辱不告状，用结果导向话术；给家长沟通建议避免亲子冲突
- **技术约束**：读不到社交内容，只能靠支付前置卡点 + 截图分享；未成年人数据需监护人同意

## 风险分析

### 最可能的失败原因

1. 误报过高导致用户直接关掉提醒、产品被弃用（中青为主，老人同）
2. 合成语音 / 换脸在未见过的方案上失效，高准确率往往只在自建测试集上成立（老 + 中青）
3. 通报发出但闭环断裂：老人不接电话、中青抵触被通报、监护人不知道怎么处理（老 + 中青）

### 预防措施

1. 低误报优先：三档分级而非二元判定，可疑级静默；分角色阈值基线；"这不是诈骗"一键反馈回流评测集
2. 可解释 + 知识库检索：声学特征 + 行为特征 + 相似案例输出证据链；不确定时降级为"建议挂断回拨核实"；测试集必须含未参与训练的合成样本
3. 干预设计成可执行动作：监护人收到动作卡（回拨、冻结、报警），老人侧语音 + 单一按钮，中青提供隐私模式

### 早期预警信号

1. "这不是诈骗"反馈率上升、通知关闭率上升、提醒触达率下降
2. 音频 / 视频模态单独测的准确率显著低于文本；新合成样本上 F1 明显低于历史；置信度集中在中低区间比例升高
3. 预警后"未完成转账 / 已联系监护人"转化率下降；通报已读率回拨率低；同一用户短期反复触发同类预警
